# Chrome extensions

A few small Chrome extensions. None of them is on the Chrome Web Store: you
load them yourself in a couple of minutes, with the steps in each extension's
README.

| Extension | What it does |
|---|---|
| [Followers Exporter for LinkedIn Pages](linkedin-followers-exporter/) | Exports the latest followers of a LinkedIn Page you manage, as a CSV or to your own webhook (n8n, Make, Zapier, Clay) |

## Download

Each extension is attached as a zip to the
[latest release](https://github.com/francoistb95/chrome-extensions/releases/latest).
Unzip it, then follow the extension's README.
